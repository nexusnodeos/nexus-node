# Snapshot de Supabase — v0.9.0-pilot-ready

**Fecha:** 2026-08-03
**Proyecto:** nexus-node (`wqochjmyjqebsnsxgytn`, us-east-1, Postgres 17.6)
**Git tag correspondiente:** `v0.9.0-pilot-ready`

⚠️ **Naturaleza de este snapshot:** esto es un documento de **introspección de estructura**
(tablas, columnas, políticas RLS, funciones, cron jobs) generado por consulta directa al
catálogo de Postgres — **no es un `pg_dump` ejecutable**. No pude correr `supabase db dump`
real porque el sandbox de Claude tiene bloqueado el acceso de red a `*.supabase.co`. Para un
dump SQL restaurable de verdad, correr desde una máquina con acceso:
```bash
supabase db dump -f schema_v0.9.0.sql
supabase db dump --data-only -f data_v0.9.0.sql
```
Este documento **no incluye ningún dato real** (solo estructura y conteos) porque el repo
es público — un dump de datos reales (RFC, montos, comprobantes) nunca debe committearse aquí.

## Funciones de negocio activas (excluye funciones internas de pgvector)

- `is_admin()` — chequeo de rol admin usado en políticas RLS
- `get_precios_lme()` — último precio de cobre
- `get_available_lots()` — lotes con estatus `publicado`
- `reserve_lot(p_lote_id, p_comprador_id)` — reserva con locking pesimista (`FOR UPDATE NOWAIT`, `lock_timeout=5s`)
- `reserve_lot_atomic(p_lot_id, p_buyer_id)` — ⚠️ existe una segunda función de reserva, agregada por otro colaborador; **pendiente de revisión** para confirmar cuál es la oficial y evitar dos caminos de reserva compitiendo
- `expirar_reservas_desatendidas()` — libera lotes reservados hace más de 10 min sin depósito
- `buscar_documentos_similares(query_embedding, umbral_similitud, limite)` — búsqueda por similitud de coseno (pgvector)
- `actualizar_timestamp_escrow()` — trigger de `escrow_transactions.actualizado_en`
- `disparar_webhook_escrow_status()`, `disparar_webhook_lote_publicado()`, `disparar_webhook_documento_nuevo()` — triggers de Database Webhooks
- `fn_matchmaker_generar_matches(p_lote_id)`, `fn_matchmaker_recascadear()`, `fn_trigger_matchmaker_on_publish()` — motor de matching (agregado por otro colaborador)
- `fn_calcular_pricing_deal_maker()`, `fn_forzar_comision_escrow_desde_lote()` — pricing/comisión (agregado por otro colaborador)
- `disparar_outreach_dual()`, `fn_reintentar_sdr_lotes_pendientes()` — outreach/SDR (agregado por otro colaborador)
- `handle_new_user()` — probablemente trigger de `auth.users` (agregado por otro colaborador)
